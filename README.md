# Fisherman's Swap

Fisherman's Swap is a Minecraft plugin that enhances the fishing experience by allowing players to swap positions with mobs when they catch them with a fishing rod. If the fishing hook lands in an area without any mobs, the player will be teleported to the hook's location. This plugin is perfect for players who enjoy interactive and dynamic gameplay.

## Install

1. Download the plugin JAR file from the GitHub repository.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart or reload your Minecraft server to enable the plugin.

## Use

1. Hold a fishing rod in your hand.
2. Right-click to cast the fishing line.
3. If you catch a mob, you will swap positions with it.
4. If the fishing hook lands in an area without any mobs, you will be teleported to the hook's location.
